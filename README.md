# Second Leash Hub — MVP v2

A mobile-friendly prototype for Second Leash operations.

## Included
- Second Leash logo and brand palette
- Admin dashboard
- Dog records and dog detail view
- Foster records
- Owner/reunification area
- Placements
- Foster check-in schedule rules
- Medical, expenses and documents placeholders
- Volunteer profiles and volunteer needs
- Users & permissions model

## Access model planned
- Brandie: Super Admin
- Michelle: Co-Admin
- Fosters: only their own profile and assigned dogs
- Volunteers: volunteer profile, opportunities and assignments
- Owners: no portal access

## Important
This is a prototype only. It uses browser-side demo data. Do not enter real confidential owner, foster, medical, or financial information until a secure authenticated database/backend is connected.
